# OpenDH

Open-source implementation of CEN/TS 18356, the European standard for insurance data interoperability.

## What this is

OpenDH is building an open, independent reference implementation of EN 18356-1 and CEN/TS 18356-2. The first component is a motor insurance record validator, funded through NLnet.

## Status

In early development. This site and the code will grow together, in this organization's repositories.
